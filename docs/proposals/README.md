本目录用于**集中孵化**尚未定案的功能提案、架构设想与选型方案，采用单文件 RFC 形式对齐，避免未定案内容污染 `reference/` 等权威象限。

## 使用规则

1. **命名**：`RFC-<四位序号>-<kebab-case 主题>.md`，例如 `RFC-0001-gpu-vendor-support.md`；
2. **状态流转**：草案 (Draft) → 评审中 (In Review) → 已接受 (Accepted) → 已实现 (Implemented) / 已废弃 (Superseded)；
3. **结晶下沉**：方案获批后，把契约、规则与设计解构沉淀到对应象限，本目录只保留索引与决策脉络；
4. **归档**：已实现或已废弃的提案移入 `archive/`，并在文件头标注结论与落地位置。
