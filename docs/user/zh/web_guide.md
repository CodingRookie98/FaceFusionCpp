## 1. 启动 Web 界面

在可执行文件所在目录运行：

**Linux (Bash)**:
```bash
./ffc --web
```

**Windows (PowerShell)**:
```powershell
.\ffc.exe --web
```

默认根据 `app.yaml` 监听 `http://0.0.0.0:8000`，浏览器访问 `http://127.0.0.1:8000`。

常用参数：

| 参数 | 说明 | 默认值 |
| :--- | :--- | :--- |
| `--web-port` | 服务端口（优先读取 `app.yaml` 中的 `web.port`） | `8000` |
| `--web-host` | 绑定地址（优先读取 `app.yaml` 中的 `web.host`） | `0.0.0.0` |
| `--web-root` | 前端静态资源目录（优先读取 `app.yaml` 中的 `web.web_root`） | `assets/web` |

> [!NOTE]
> `--web` 与快捷模式（`-s/-t/-o`）及任务配置模式（`-c`）互斥。

## 2. Studio Workbench 沉浸式工作台

Web UI 采用专为 AI 视觉创作打造的 **Deep Studio Dark 单屏工作台**：

### 2.1 左栏：素材资产池与任务队列 (Asset & Queue Panel)
左侧面板支持 3 个一级 Tab 并列切换：
- **源素材 (Sources)**：管理用于特征提取的源素材，支持多选并发上传与拖拽导入；点击任意源素材项即可在中间画布进行高清预览；
- **目标素材 (Targets)**：管理待处理的目标图片或视频，点击后即时投射到中央主视口并触发自动人脸检测与标注；
- **任务队列 (Task Queue)**：展示当前所有排队中、处理中、已完成与异常任务卡片。每个任务卡片提供：
  - 【**⬆️ 提升优先级**】：增大排队 priority 优先被后台 Worker 调度；
  - 【**⬇️ 降低优先级**】：减少排队 priority；
  - 【**✕ 取消任务**】：直接取消排队中或正在运行的任务；
  - **点击即时联动**：点击任意任务卡片，中间主画布即可联动预览该任务的目标图、实时进度百分比或已完成渲染结果。
  - **任务物理隔离**：每个任务产物均保存在专属独立子目录（`./output/<uuid>/`），杜绝同名结果覆盖或跨任务串扰。

### 2.2 中栏：全态感知主画布与对比视口 (Omni Viewport Canvas)
- **全态智能感知联动**：
  - **源素材态**：展示所选源素材的高清大图/视频及元信息（`源素材: <filename>`），原始素材模式默认禁用卷帘对比；
  - **目标素材态**：展示目标底图并叠加 WYSIWYG 人脸框多选与反选（红框 `✓ 已选` $\leftrightarrow$ 青蓝框 `○ 未选`），顶部提供【全选】与【清空】批量按钮；
  - **任务队列态**：排队中展示底图与排队序号；处理中叠加半透明实时帧进度波浪与 FPS 遥测；已完成展示渲染成果并自动进入对比模式。
- **多模态视口与对比矩阵**：
  - **处理结果 (Result)**：独立全图预览处理后资产，并支持【**下载结果**】；
  - **卷帘对比 (Compare)**：在任务完成或【渲染预览】成功后开放，左右卷帘无级拖动滑块对比前后效果；
  - **局部放大镜 (Loupe)**：光标悬停时激活 2.8x 高倍放大镜审查眼部、发丝与肤质融合度；
  - **视频同频对齐**：原视频与处理后视频双轨同频对齐播放。

### 2.3 右栏：动态管线编排器 (Pipeline Editor)
- **官方智能预设**：一键切换“极速单人换脸”、“高清写真重塑”、“多人精准多脸替换”、“影视级全流程超分”；
- **多实例流水线**：支持在同一管线中挂载多个同类型 Processor（如针对不同角色挂载多个独立配置参考脸的 `face_swapper`）；
- **参数即时调节**：模型切换、选择器模式、`blend_factor` / `restore_factor` / `enhance_factor` 强度滑块双向微调；
- **双核心操作 CTA**：
  - 【**⚡ 渲染预览**】：单帧轻量即时推理（不加入任务队列）。对于目标为视频的素材，在视频播放暂停/停止时可用，精准截取当前画面帧并进行人脸替换与单帧渲染，完成后自动切入卷帘对比；
  - 【**➕ 加入队列**】：将完整任务配置与素材打包加入持久化后台队列并返回任务 ID，自动切换到左侧队列监控进度。

### 2.4 底栏：实时遥测与任务调度 HUD (Telemetry HUD)
- **实时遥测指标**：C++ Core 在线状态、当前任务帧进度百分比、实时推理 FPS；
- **队列调度与优先级**：查看排队任务序号，一键提升/降低排队优先级（P 值越大越优先调度），一键取消任务；
- **历史记录抽屉**：点击“历史成果”随时浏览历史完成任务，一键载入工作台比对。

## 3. REST API 契约摘要

| 方法 | 路径 | 说明 |
| :--- | :--- | :--- |
| `GET` | `/api/health` | 健康检查（含版本与状态） |
| `GET` | `/api/processors` | 处理器列表与参数元数据 |
| `POST` | `/api/preview_render` | 单帧即时渲染预览（支持 Base64 截帧，不入队列） |
| `POST` | `/api/tasks` | 提交任务（分配独立专属输出目录 `./output/<uuid>`） |
| `GET` | `/api/tasks` | 全部任务列表（含状态、进度与队列位置） |
| `GET` | `/api/tasks/{id}` | 任务详情（含隔离子目录下的结果文件列表） |
| `POST` | `/api/tasks/{id}/cancel` | 取消排队或执行中的任务 |
| `POST` | `/api/tasks/{id}/priority` | 调整任务在队列中的优先级 |
| `GET` | `/api/tasks/{id}/progress` | 查询任务最新进度 |
| `POST` | `/api/faces` | 素材人脸检测标注与关键点分析 |
| `POST` | `/api/upload` | 素材上传至临时目录 |
| `GET` | `/media/...` | 素材与结果文件访问（视频支持 HTTP Range 流媒体） |
