## 1. 启动 Web 界面

在可执行文件所在目录运行：

**Linux (Bash)**:
```bash
./ffc --web
```

**Windows (PowerShell)**:
```powershell
.\ffc.exe --web
```

默认监听 `http://0.0.0.0:8000`，浏览器访问 `http://127.0.0.1:8000`。

常用参数：

| 参数 | 说明 | 默认值 |
| :--- | :--- | :--- |
| `--web-port` | 服务端口 | `8000` |
| `--web-host` | 绑定地址 | `0.0.0.0` |
| `--web-root` | 前端静态资源目录（开发调试可指向 `web/dist`） | `assets/web` |

> [!NOTE]
> `--web` 与快捷模式（`-s/-t/-o`）及任务配置模式（`-c`）互斥。

## 2. Studio Workbench 沉浸式工作台

Web UI V2 采用专为 AI 视觉创作打造的 **Deep Studio Dark 单屏工作台**：

### 2.1 左栏：素材资产池 (Asset Pool)
- **多文件并发上传与拖拽导入**：支持在文件选择器中一次性选中多个 JPG、PNG、BMP、MP4、MOV 文件批量上传，或直接拖拽多份文件至素材池；面板提供 `正在上传 (N/M)...` 实时进度提示；
- **源人脸图库 (Sources)**：管理用于特征提取的源人脸，提供内置测试样张（Lenna / 男士肖像 / 女士肖像）一键载入；
- **目标素材池 (Targets)**：管理待处理的目标图片或视频文件，选中后即时投射到中央主视口并触发自动人脸检测；
- **视频时间轴截帧**：视频素材内置播放器与时间轴抓帧工具，可一键提取任意关键帧并自动加入源或目标素材池。

### 2.2 中栏：交互视口与主画布 (Viewport Canvas)
- **WYSIWYG 人脸多选与反选**：
  - **默认全选**：素材载入后自动执行人脸检测，默认将所有人脸标记为选中状态；
  - **单击切换选择**：单击人脸框或顶部标签即可反选/切换（选中为人脸红框 `✓ 已选 #N`，未选为人脸青蓝框 `○ 未选 #N`）；
  - **批量快捷控制**：画布顶部工具栏实时显示 `已选 N/M 张人脸`，并提供【**全选**】与【**清空**】快捷按钮；
  - **智能管线联动**：单选人脸自动绑定为指定步骤的 `reference` 参考人脸；多选/全选人脸自动切换为 `many` 策略并传递指定人脸索引。
- **多模态视口与对比矩阵**：
  - **标注画布 (Canvas)**：素材原图审查与人脸交互点选标注；
  - **处理结果 (Result)**：任务完成后可直接切换至全图结果视图独立审查，并支持一键【**下载结果**】；
  - **卷帘对比 (Compare)**：任务完成后自动开启左右卷帘无级分割对比，前后效果一目了然；原图画布下方亦提供常驻快捷浮条一键直达；
  - **局部放大镜 (Loupe)**：光标悬停时激活 2.8x 高倍放大镜，精细核验眼部细节、五官边缘与肤质融合度；
  - **视频同频对齐**：原视频与处理后视频双轨同频对齐播放。

### 2.3 右栏：动态管线编排器 (Pipeline Editor)
- **官方智能预设**：一键切换“极速单人换脸”、“高清写真重塑”、“多人精准多脸替换”、“影视级全流程超分”；
- **多实例流水线**：支持在同一管线中挂载多个同类型 Processor（如针对不同角色挂载多个独立配置参考脸的 `face_swapper`）；
- **参数即时调节**：模型切换、选择器模式、`blend_factor` / `restore_factor` / `enhance_factor` 强度滑块双向微调。

### 2.4 底栏：实时遥测与任务调度 HUD (Telemetry HUD)
- **实时遥测指标**：C++ Core 在线状态、当前任务帧进度百分比、实时推理 FPS；
- **队列调度与优先级**：查看排队任务序号，一键提升/降低排队优先级（P 值越大越优先调度），一键取消任务；
- **历史记录抽屉**：点击“历史成果”随时浏览历史完成任务，一键载入工作台比对。

## 3. REST API 契约摘要

| 方法 | 路径 | 说明 |
| :--- | :--- | :--- |
| `GET` | `/api/health` | 健康检查（含版本与状态） |
| `GET` | `/api/processors` | 处理器列表与参数元数据 |
| `POST` | `/api/tasks` | 提交任务（支持 `pipeline_steps` 结构化多步骤数组） |
| `GET` | `/api/tasks` | 全部任务列表（含状态、进度与队列位置） |
| `GET` | `/api/tasks/{id}` | 任务详情（含结果文件列表） |
| `POST` | `/api/tasks/{id}/cancel` | 取消排队或执行中的任务 |
| `POST` | `/api/tasks/{id}/priority` | 调整任务在队列中的优先级 |
| `GET` | `/api/tasks/{id}/progress` | 查询任务最新进度 |
| `POST` | `/api/faces` | 素材人脸检测标注与关键点分析 |
| `POST` | `/api/upload` | 素材上传至临时目录 |
| `GET` | `/media/...` | 素材与结果文件访问（视频支持 HTTP Range 流媒体） |
